# ISS-005: Улучшить алгоритм поиска по ключевым словам

## Type
feature

## Status
completed

## Summary
Внедрить точный поиск по словам (границы слов) и лемматизацию (стемминг) для поиска корней вместо точного соответствия окончаний.

## Context
Из ресерча `ISS-002` выявлено, что базовый `includes` слишком глуп. Он находит "квартира" внутри "квартиранты", но не находит "квартиру", если в правиле указана только "квартира". Это базовая проблема NLP.

## Goal
Система должна уметь искать по точным границам слова и игнорировать окончания, повысив тем самым точность и полноту совпадений для русско- и сербскоязычных каналов.

## Scope
Что входит в задачу:
- Интеграция библиотеки-стеммера (например, snowball stemmer) или алгоритма нормализации окончаний.
- Изменение логики сравнения с `includes` на пословное сопоставление токенов.

Что не входит в задачу:
- Полноценный морфологический анализ (это слишком тяжело).
