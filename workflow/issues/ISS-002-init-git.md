# ISS-002: Инициализация Git репозитория

## Type
chore

## Status
in_progress

## Summary
Инициализация git репозитория в текущем проекте с настройкой корректного `.gitignore`.

## Context
Проект на текущий момент не находится под контролем версий. Для стабильной разработки и отслеживания изменений необходимо инициализировать git.

## Goal
- Инициализированный git репозиторий.
- Ветка по умолчанию — `main`.
- Настроенный `.gitignore`, исключающий зависимости, секреты и локальные хранилища.
- Первый коммит со всеми файлами проекта (за исключением игнорируемых).

## Scope
- Создание `.gitignore`.
- Выполнение `git init`.
- Установка главной ветки в `main`.
- Создание первого коммита.
