# ISS-004: Исправить регулярку в normalize.js

## Type
bug

## Status
done

## Summary
Регулярное выражение в `src/normalize.js` излишне строго удаляет некоторые полезные символы (дефисы), а также содержит бессмысленный сегмент `dinдинара`.

## Context
В рамках `ISS-002` обнаружено, что нормализатор портит структуру сложных слов. Слово `1-комнатная` становится `1 комнатная`, что может мешать точному поиску по фразе "1-комнатная". Конструкция `[^\p{L}\p{N}\s€$£¥dinдинара]` содержит избыточное упоминание латинских и кириллических букв внутри списка отрицания из-за непонимания как работает `\p{L}`.

## Goal
Упростить и исправить регулярное выражение для очистки текста: оставлять внутренние дефисы в словах, удалить логический мусор.

## Scope

Что не входит в задачу:
- Добавление лемматизации (этим занимается ISS-005).
