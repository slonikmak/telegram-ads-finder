# Workflow

Эта директория содержит минимальный набор документации для управления процессами и фиксации текущего состояния проекта `Telegram Advanced Search`. 

> **Примечание:** Документация была инициализирована уже после того, как проект начал работу. Она описывает актуальное состояние "как есть сейчас", а не пытается стать исторической ретроспективой.

## Структура

- `project.md` — актуальная картина проекта (компоненты, контекст, ограничения).
- `rules.md` — правила ведения работы и документации.
- `issues/` — директория для фиксации задач и изменений.

В случае возникновения крупных фичей могут быть добавлены папки `reqs/`, `plans/` или `research/`, однако их создание требуется только при реальной и явной необходимости. Не усложняйте структуру без повода.

## Как начать работу

Любая новая задача или изменение начинается с создания нового файла-issue в папке `issues/`. После принятия решений или завершения задачи, важная информация должна быть сразу перенесена в `project.md` для сохранения актуальной архитектурной картины проекта.
