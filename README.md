# Telegram Advanced Search

Сервис для мониторинга Telegram-каналов в реальном времени с фильтрацией по ключевым словам и ценам.

## Основные возможности
*   Мониторинг указанных каналов в реальном времени.
*   Извлечение цен (EUR, RSD) и их нормализация.
*   Фильтрация по сложным правилам (включения, исключения, диапазоны цен).
*   Уведомления через Telegram-бота.
*   История сообщений и совпадений в SQLite.

---

## Настройка и получение токенов

Для работы сервиса необходимо получить учетные данные для пользовательского клиента (GramJS) и бота-уведомителя.

### 1. Получение API_ID и API_HASH (User Client)
1.  Перейдите на [my.telegram.org](https://my.telegram.org).
2.  Авторизуйтесь и выберите **"API development tools"**.
3.  Создайте приложение и скопируйте **App api_id** и **App api_hash**.

### 2. Получение токена бота (Notifier Bot)
1.  У [@BotFather](https://t.me/BotFather) создайте нового бота (`/newbot`).
2.  Скопируйте полученный **HTTP API token**.

### 3. Получение вашего Chat ID
1.  Узнайте свой ID через [@userinfobot](https://t.me/userinfobot).
2.  Скопируйте его для поля `ALLOWED_USERS`. Если нужно указать нескольких пользователей, перечислите их ID через запятую (например: `123456789,987654321`).

## Установка и запуск

1.  **Клонируйте репозиторий** и установите зависимости:
    ```bash
    npm install
    ```
2.  **Настройте окружение**:
    Создайте файл `.env` на основе `.env.example` и заполните полученными токенами.
3.  **Настройте правила и каналы**:
    *   `config/channels.yaml`: Список каналов для мониторинга.
    *   `config/rules.yaml`: Правила фильтрации (ключевые слова, цены).
4.  **Запустите сервис**:
    ```bash
    node src/index.js
    ```

---

## Структура проекта
*   `src/index.js` — точка входа и оркестрация.
*   `src/telegram.js` — клиент GramJS для прослушивания каналов.
*   `src/matcher.js` — логика сопоставления с правилами.
*   `src/price.js` — парсинг цен.
*   `src/db.js` — работа с SQLite.
*   `config/` — файлы конфигурации YAML.

> [!NOTE]
> При первом запуске в консоли потребуется ввести номер телефона и код подтверждения от Telegram. Сессия будет автоматически сохранена в `data/session/session.txt`, и при следующих запусках повторная авторизация не потребуется.
